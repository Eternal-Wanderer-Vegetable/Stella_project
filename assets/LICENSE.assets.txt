1. DEFINITION OF ARTISTIC ASSETS

For the purposes of this project, "Artistic Assets" means the original
visual, graphic, typographic, audio, and design works that are included
in the Program and identified in Section 3 of this file.

This definition includes original source images, textures, previews,
compressed variants, generated artwork, and platform-specific copies
of those works. The scope is determined by the complete file list in
Section 3 and is not limited to one particular directory or file
extension.
