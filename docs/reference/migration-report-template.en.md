## Safety and Rollback

- The old directory remains read-only throughout the operation.
- A failure does not overwrite user data and can be retried after remediation.
- Configuration merging changes only the target directory; unrecognized settings
  are preserved or listed according to the migration rules.
- Runtime, component, and model packages are checksum-verified; a failed import
  does not switch the active version.
