1. DEFINITION OF ARTISTIC ASSETS

For the purposes of this project, "Artistic Assets" are defined as
the following files and file types located within the project
repository:

(a) Image and Texture Files:
    - All files with the following extensions: .png, .jpg, .jpeg, .gif,
      .bmp, .tga, .psd, .xcf, .svg, .webp
    - Located in the directories: assets/textures/, assets/ui/,
      assets/sprites/, and assets/images/

(b) 3D Model and Animation Files:
    - All files with the following extensions: .blend, .fbx, .obj,
      .gltf, .glb, .dae, .3ds, .pmx, .vrm
    - Located in the directories: assets/models/, assets/characters/,
      and assets/environment/

(c) Audio and Sound Files:
    - All files with the following extensions: .wav, .mp3, .ogg,
      .flac, .aac, .opus, .mid
    - Located in the directories: assets/audio/, assets/music/,
      and assets/sfx/

(d) Font Files:
    - All files with the following extensions: .ttf, .otf, .woff,
      .woff2
    - Located in the directories: assets/fonts/

(e) Visual Design Source Files:
    - All files with the following extensions: .psd, .xcf, .ai, .fig,
      .sketch, .xd
    - Located in the directories: assets/sources/, assets/design/
