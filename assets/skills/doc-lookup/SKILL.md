# doc-lookup（只读文档检索）

按以下步骤查找并摘录文档：

1. 用 `list_files` 列出 `docs/` 下的文件，挑出名称与问题最贴近的一两个。
2. 用 `read_file` 读取目标文档（每次只读一个，找到相关段落即可停）。
3. 把与问题直接相关的**原文**摘录进结果（不超过 300 字），并注明来源文件名。

边界约束：

- **只读**：本技能不允许创建、修改或删除任何文件。
- 摘录必须逐字来自文档，不要改写数字、路径或配置键名。
- 找不到相关文档时，如实说明「文档中没有找到」，不要凭空编造。
