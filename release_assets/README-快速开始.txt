====================================================
  Stella 快速开始
====================================================

本程序是 Windows 免安装版：解压后可双击 Stella.exe 使用图形界面，
也可双击 start.bat 使用命令行流程，无需自行安装 Python。

----------------------------------------------------
 第一步：安装并登录 NapCat
----------------------------------------------------
1. 下载 NapCatQQ Desktop：
   https://github.com/NapNeko/NapCatQQ-Desktop
2. 安装后扫码登录你的 QQ（必须人工扫码）。
3. 在 NapCat WebUI 的「网络配置」里添加「WebSocket 客户端」，
   地址填：
     ws://127.0.0.1:8080/onebot/v11/ws

----------------------------------------------------
 第二步：安装 LM Studio 并加载两个模型
----------------------------------------------------
1. 下载安装 LM Studio：https://lmstudio.ai/
2. 加载主聊天模型（.env 里填 LM_STUDIO_MODEL，示例：
   google/gemma-4-26b-a4b-qat）。该模型独占 GPU。
3. 加载记忆整理模型（.env 里填 CONSOLIDATION_LM_STUDIO_MODEL，
   示例：google/gemma-4-e4b）。在模型设置里把 GPU Offload 设为 0，
   让它走纯 CPU 推理——这是双模型并行的前提：聊天用 GPU、
   记忆整理用 CPU，两者同时运行互不挤占显存。

----------------------------------------------------
 第三步：启动 Stella
----------------------------------------------------
1. 双击 start.bat。
2. 首次运行会自动下载约 100MB 的 Python 运行时并安装依赖，
   请耐心等待（可能需几分钟）。
3. 下载与安装完成后会进入配置向导，回答 5 个必答项即可。
4. 启动成功后，在群里 @ 机器人即可开始对话。

----------------------------------------------------
 出问题了？
----------------------------------------------------
双击 doctor.bat 运行环境自检，把输出复制下来提交 issue：
  https://github.com/Eternal-Wanderer-Vegetable/Stella_project/issues
提交时请附上 start.bat 窗口里出现的报错信息。

----------------------------------------------------
 安全软件提示
----------------------------------------------------
start.bat 会下载并运行 Python 并安装依赖，部分杀软可能拦截。
若安装过程卡住或被隔离，请把本目录加入杀软信任列表后重试。

----------------------------------------------------
 升级到新版本
----------------------------------------------------
1. 先运行 stop.bat 停止程序
2. 把新版本解压到一个新目录
3. 双击 Stella.exe（或 start.bat），程序会自动找到旧目录，
   问你要不要导入。确认即可——配置、记忆、人格、空间设置、
   已装插件都会搬过来，数据库也会自动升级到新版本。
   命令行用法：python -m deploy migrate --dry-run  （先看预览）
               python -m deploy migrate            （执行导入）

说明：
- 全程只读旧目录。无论成败，旧安装都还在原地能跑，可以放心重试。
- 导入前会自动备份数据库，报告写在 migration_report.md 里。
- 自动找不到旧目录时，用 --from 指定，或在「配置导入」页面里填路径
  （在「配置」页面底部可以打开它）。
- runtime\ 会自动复用，省掉约 100MB 的重新下载。
- 从 2.x 升级过来也不需要丢记忆：旧库会自动迁移（列改名、按共享空间重新归属、
  用户画像归入其消息最多的那个空间）。

----------------------------------------------------
 我的数据存在哪里？
----------------------------------------------------
运行 python -m deploy paths 可以看到「用户数据目录」的位置
（doctor.bat 的报告里也会显示）。

- 旧版本升级上来的安装：数据仍在安装目录内，与以前一样。
- 全新安装：数据放在程序目录**旁边**的 StellaData\ 里，与程序分开：

    D:\你的目录\
      Stella-v3.1.0-win64\   ← 程序（升级时整个换掉，可以放心删）
      StellaData\            ← 你的数据（升级时一动不动）

  以后升级只需换掉程序目录，数据不用动。

  *** 重要：StellaData\ 与版本文件夹是平级的，不在它里面。 ***
  升级后清理旧的 Stella-v3.0.0-win64\ 之类的文件夹是安全的，
  不会碰到你的数据。

- 想把程序和数据放在一起（比如整个拷进 U 盘）：在程序目录里手工
  建一个 StellaData\ 子目录，程序会优先用它。代价是这个目录会跟着
  程序目录一起被替换或删除，升级前务必先导入或备份。

备份时整个数据目录一起拷走即可。
