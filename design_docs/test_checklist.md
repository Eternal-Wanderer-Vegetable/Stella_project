# 测试指令清单

面向手动验收的完整清单，覆盖 Capability Router / Comes / AstrBot 兼容层 / 记忆 / 部署五条链路。
**每条都给出「输入 → 期望 → 去哪儿看」**，其中「去哪儿看」全部落在 `logs/`（见 [日志](../docs/configuration.md#日志)）。

当前生效开关（`.env` 未覆盖即为此值）：

| 开关 | 值 | 影响 |
|---|---|---|
| `ALLOWED_GROUPS` | `263402786,1074455954` | 只有这两个群会被响应 |
| `ASTRBOT_WAKE_PREFIXES` | `/` | 插件指令必须以 `/` 开头，或 @ 机器人 |
| `ASTRBOT_COMPAT_ALLOW_PRIVATE` | `true` | 私聊也能触发插件指令 |
| `ROUTER_TOOL_THRESHOLD` | `0.70` | 语义分低于此值不调工具 |
| `ROUTER_CAPABILITY_MARGIN` | `0.12` | 只执行与最高分相差 0.12 以内的能力 |
| `ROUTER_FALLBACK_ENABLED` | `false` | Level 2 关闭 |
| `ROUTER_GATE_MEMORY` | `false` | 记忆检索无条件执行 |
| `COMES_DIRECT_CALL_NO_ARGS` | `true` | 单工具且无必填参数时跳过 LLM 直调 |
| `PROACTIVE_TOGGLE_ADMINS` | 空 | **管理员仅按 QQ 群身份判定（群主/管理员）** |

## 3. 负例：不该调工具

**验证点：路由判定行里没有 `+tool`，且 `未达工具置信线 0.70`。**

| # | 输入 | 说明 |

## 4. Comes 执行

| # | 输入 | 期望路径 | 验证点 |
|---|---|---|---|
| 4.1 | 2.1 / 2.4 任一 | **直调**（无必填参数） | 工具执行行里有「直调」，耗时 < 1s |
| 4.2 | `帮我查一下《赛博朋克 边缘行者》的评分` | **受限 agent**（`anime.search` 的 keyword 必填） | 工具执行行里是「agent」而非「直调」 |
| 4.3 | 1.4（带真实 UID） | **受限 agent**（`video.dynamics` 的 uid 必填） | 同上；且模型要把 UID 正确填进参数 |
| 4.4 | 断开 LM Studio 后发 2.1 | 路由降级，照常回复，不崩 | `路由判定 ... via default`；无异常堆栈 |
| 4.5 | 关掉插件（挪走 `data/plugins/`）后发 2.1 | `能力 X 的工具全部不可用` → 不进 prompt | 工具执行行 `failed` + 原因 |

> **4.2 / 4.3 是本轮最该测的**：受限 agent 路径（`COMES_SYSTEM_PROMPT` + objective + 工具 schema）至今**一次都没被真正走到过**，参数填充、`max_steps`、「模型拒调 → failed → summary 不进 prompt」整条链全未实测。

## 6. AstrBot 插件指令（bilibili 插件）

前缀 `/`，或 @ 机器人后跟指令。**中文别名同样有效。**

| # | 指令 | 权限 | 期望 |
|---|---|---|---|
| 6.1 | `/bili_sub_list` 或 `/订阅列表` | 普通 | 返回当前订阅列表（可能为空） |
| 6.2 | `/bili_sub 29233734 ` 或 `/订阅动态 29233734 ` | 普通 | 添加订阅成功 |
| 6.3 | `/bili_sub_del 29233734` 或 `/订阅删除 29233734` | 普通 | 删除成功 |
| 6.4 | `/bili_sub_test 29233734` 或 `/订阅测试 29233734` | 普通 | 拉取动态 → **渲染失败降级为纯文本**（见 §7.2） |
| 6.5 | `/bili_card_style` 或 `/卡片样式` | **管理员** | 列出可用样式 |
| 6.6 | `/bili_login` | **管理员** | 输出登录二维码或提示 |
| 6.7 | `/bili_logout` | **管理员** | 登出 |
| 6.8 | `/bili_global_list` 或 `/全局列表` | **管理员** | 列出所有订阅者 |
| 6.9 | `/bili_global_sub <UMO> <UID>` 或 `/全局订阅 ...` | **管理员** | 代其他会话添加订阅 |
| 6.10 | `/bili_global_del <UMO>` 或 `/全局删除 ...` | **管理员** | 删除某会话全部订阅 |
| 6.11 | 用**非管理员**账号发 6.5 | 回复「您(ID: xxx)的权限不足以使用此指令。」 | 权限链路生效 |

> 管理员判定：QQ 群主/管理员身份，**或** `.env` 的 `PROACTIVE_TOGGLE_ADMINS` 里列出的 QQ 号。
> 当前 `PROACTIVE_TOGGLE_ADMINS` 为空，所以只有群主/群管能过 6.5–6.10。测试前要么用群管账号，要么先把自己的 QQ 号填进去。

## 11. 已知失败 / 已知不支持（**预期就是这样，不要当 bug 报**）

| # | 现象 | 原因 | 状态 |
|---|---|---|---|
| 11.1 | `我最近在追新番` 会触发 `anime.recommend`（得 0.837） | 余弦分不开「陈述 X」和「请求 X」。抬阈值治不了：正样本下界 0.851，只剩 0.016 余量 | 待 Level 2；已作为已知失败留在 `capability/router/benchmark/acg.json` |
| 11.2 | 视频卡片/动态推送**永远**渲染失败，降级为纯文本 + 封面图 | `Star.html_render` 在兼容层里是 `StellaCompatNotSupported`（需要无头浏览器） | 未实现的兼容面；插件每次还会**重试 3 次、每次间隔 2s**，白等约 4s |
| 11.3 | 工具结果进 prompt 时是原文截断（300 字符，会切在条目中间） | 无参直调没有 LLM，`summary` 退化为 `from_tool_outputs` 截断 | 第 2/3 步处理 |
| 11.4 | 每条被语义路由的消息多约 2.5s | embedding 与 27B 聊天模型共用同一个 LM Studio 实例，发生模型换入换出（编码本身实测约 70ms） | 把 embedding 指到独立实例/端口即可 |
| 11.5 | Top-N 列表类工具结果只有前 3~4 条进 prompt | 同 11.3 的截断 | 同 11.3 |
| 11.6 | 三个 Markdown 日志无上限增长 | 只有 `stella.jsonl` 有轮转（10MB / 保留 5 份） | 需要时手动清理 |
